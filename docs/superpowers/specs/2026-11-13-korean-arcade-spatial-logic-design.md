# 한국식 상가·실내 공간 재구성 설계

## 목표
현재 `EternalNightCityLab`의 미국식 반복 창면, 비어 있는 실내 상자, 기능과 맞지 않는 부품 배치를 교정한다. 세계관의 한국식 낡은 상가·시장·점포·가벽·복도·공중 연결을 보존한다.

## 요구
- A1 외벽은 건물의 시대/몸체 재료를 유지하고, 점포 1~2층 전면에 개구부·간판을 집중시킨다. 주거·공방·시설 외벽은 구분한다. 반복 커튼월 금지.
- A2 점포 내부는 출입구, 판매 공간, 실제 분리된 뒤편 창고/서비스실로 구성한다. 가벽과 2블록 높이의 통과구가 실제 월드에 존재해야 한다. 옥상·소형 점포도 실제 출입 방향과 일치한다.
- A3 벽·창·셔터·간판·환풍기는 건물 용도와 입면 위계에 따라 배치한다. 해시만으로 미용품을 곳곳에 놓는 형태 금지.
- A4 대단지 골목에는 소규모 점포가 자연스레 연속되도록 하고 기존 포트·계단·브릿지·기존 저장 데이터를 훼손하지 않는다.

## 선택과 범위
1. **채택: 기존 절차 생성기의 룸 데이터·부지 경계·외벽 출력을 의미 기반으로 교정.** 이미 지지·계단·교량 그래프가 있어 변경 파급을 제한할 수 있다.
2. 대안: 기존 건물 전면 모델 재구성. 품질 잠재력은 높지만 세이브/충돌/성능 위험이 커 이번 범위에서 제외.
3. 대안: 새 한국식 건물 블록 세트를 추가. 부품만 증가해 공간 구조를 고치지 못하므로 제외.

## 완료 조건
- 시드 고정 설계에서 층별 점포와 서비스실 분리, 문 방향 일치, 용도별 외벽 개구부 차이 확인
- 기존 70~80층 규모, 창·계단·인테리어 부품과 출입 가능성, 조명, 기존 월드 모드 유지
- 실기기 시야·프레임·UI 검증은 별도 실행 필요, 코드 검사와 혼동하지 않음
