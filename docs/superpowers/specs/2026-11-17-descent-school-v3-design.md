# 하강 V3: 한국 학교 월드 설계

## 목적
기존 대단지 V2를 보존하면서 별도 생성 알고리즘으로 한국식 학교를 탐험하는 V3 월드를 추가한다.

## 접근법
- 채택: 좌표와 시드 기반 독립 청크 학교 생성. 다른 청크나 계획 캐시 없이 생성하므로 경계에서 동일한 결과를 만든다.
- 대안: 고정 단일 학교 모델. 구현은 간단하지만 새로운 시드와 확장성이 낮다.
- 대안: 기존 V2 도시에 학교를 삽입. 기존 생성과 저장, 성능의 회귀 위험이 커서 이번 실험에 부적합하다.

## 설계
- 모드 school-v3, 프리셋 DescentSchoolV3
- 224×224 반복 캠퍼스와 시드별 마감재 변화
- 4층 편복도 교사동, 모듈형 교실, 창문, 계단실 2곳, 층당 7블록
- 운동장/트랙, 체육관, 정문, 외곽 도로, 나무와 최소 실내 집기
- 기존 WebGL2 / 청크 / 블록 ID / 로컬 저장 구조 유지

## 범위 밖
학교 실제 도면 1:1 복제, 신규 그래픽 자산, 교직원 NPC, 학교 AI, 기존 V2 구조 변경.

## 완료 기준
청크 생성 순서 독립, 음수 좌표 정상, 입구 접근, 층간 이동, 운동장/체육관/교실 분화, 기존 월드와 저장 격리. 실제 GPU 렌더링과 조작감은 브라우저 별도 검수.
