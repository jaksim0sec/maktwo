# 영원한 밤 · 대단지 생성 알고리즘 설계

> 범위 — 단일 코어 계획의 P04. P03의 필드와 코어 경계를 받아 도시 섹션, 건물 덩어리, 입체 동선을 생성한다. P05는 이 결과를 검증하고 게임에 연결한다.

[단면 미리보기](core-floor-preview.html)에는 필드 분할, 직사각형 건물 덩어리, 지지된 상층 증축, 공중 연결교, 층별 호화도 조회가 연결되어 있다. 실내 경로, 붕괴, 시야 검증은 이 설계의 후속 단계다.

## 좌표와 책임

코어 층의 높이 범위 안에 여러 크기의 건물과 공중 공간이 함께 존재한다. 코어 슬래브, 기둥, 상위 구조물은 건축 하중을 받을 수 있는 지지체다. 보행 표면은 건물 내부 바닥, 계단참, 노출된 옥상, 아케이드, 연결교에서 나온다. 하나의 높이를 모든 건물의 출입구 높이로 공유하지 않는다.

| 입력 | 사용처 |
| --- | --- |
| `zoneAt`, `districtIdAt`, `verticalSpansAt` | 상위 평면과 소유권, 구조물 예약. 원형 개구부와 통로 진입 공간을 보존한다. `verticalSpansAt`의 통로 예약은 지지 가능한 고체로 취급하지 않는다. |
| 상위 노이즈 `N(x,z)` | 도시 섹션이 늘어나는 방향, 이웃 섹션과의 경계, 큰 빈 공간의 위치 |
| 상위 호화도 `L(x,z)` | 중심 후보의 우선도, 섹션 범위, 건물 규모의 분포, 용도 배합, 마감 |
| 상위 연결점 `{position, facing, clearance}` | 중앙·가장자리 통로와 대단지가 만나는 출입구. 아직 좌표가 제공되지 않으면 미리보기 입력으로 명시한다. |
| 층 시드, 높이 범위, 플레이어 이동 규격 | 동일 결과 재현, 건물의 수직 한계, 모든 통행 간선의 치수 검증 |

현재 모듈의 `luxuryAt`은 이미 그물형 노이즈를 합성한다. 같은 캐시에서 원본 `N`을 읽는 샘플 출력을 추가하고 `L`에 노이즈를 다시 더하지 않는다. `N`을 0으로 돌리는 호화도 진폭 설정과, 도시 형태에 사용할 원본 필드의 제공 여부는 별개다. P04의 필드 표본은 대단지 안에서만 유효하다. 상위 연결점 주위에는 통행에 필요한 3D 여유 공간을 함께 예약한다.

## 1. 흐름을 따라 도시 섹션 범위를 만든다

1. **필드 표본을 만든다.** 대단지별로 `N`, `L`, 상위 마스크를 동일 격자에서 샘플링한다. 미리보기의 시작 간격은 4블록이며, 노이즈의 가장 좁은 유효 띠를 최소 세 표본으로 읽도록 필요할 때 좁힌다. `L`은 `districtLuxuryMax`로 정규화해 절대 호화도를 유지한다. 시드마다 범위를 다시 펼치지 않는다.
2. **노이즈 띠의 방향과 분기점을 얻는다.** 주변 표본의 기울기를 모아 방향 텐서를 구한다. 변화가 가장 작은 축을 흐름 방향 `t`로 사용한다. 띠가 갈라지거나 평평해 방향 신뢰도가 낮으면 거리 비용을 등방성으로 되돌린다. 평면의 각 흐름에는 두 방향이 있으므로 각도 비교에 내적의 절댓값을 쓴다.
3. **도시 중심을 뽑는다.** 띠의 교차점, 호화도의 지역 최대점, 상위 연결점의 접속부가 후보가 된다. 시작 점수는 `0.6·L + 0.3·N + 0.1·교차도`다. 정해진 최소 간격 안에서 높은 점수만 남기고, 중심별 점수와 마스크 면적에서 목표 범위를 잡는다. 호화도가 낮고 통행 가능성이 필요한 섹션에도 소규모 중심을 배정한다. 절단된 마스크마다 중심이 적어도 하나 있어야 한다.
4. **중심들을 동시에 확장한다.** 8방향 다중 시작점 최단거리 탐색을 사용한다. 대각선이 막힌 코너를 통과할 수 없고, 상위 예약 공간에는 들어갈 수 없다. 표본 이동 비용은 다음으로 시작한다.

   ```text
   비용 = 이동 길이 × [
     1 + 0.8·(1 - 평균 N)
       + 1.2·방향 신뢰도·(1 - |이동 방향 · t|)
       + 0.6·|L(도착점) - L(출발점)|
   ]
   ```

   각 표본은 누적 비용이 가장 낮은 중심이 소유한다. 비용 동률은 고정 ID 순서로 정한다. 높은 노이즈 띠를 따라 길게, 호화도가 급격히 바뀌는 구간에서는 짧게 자라는 구조다. 호화도가 높은 연결부에서 넓은 섹션을 원하면 중심 간격과 최소 유효 면적을 키우고, 이미 자란 섹션의 경계를 사후에 무리하게 밀지 않는다.
5. **경계를 정리한다.** 가장 작은 건물과 통행 여유를 수용할 수 없는 섹션만 경계를 가장 길게 공유하고 호화도가 가까운 섹션에 합친다. 서로 이어지지 않은 조각의 ID는 분리한다. 마스크의 개구부와 통로는 경계 정리 중에도 보존한다.

섹션 경계는 건물 묶음의 성장 방향과 용도 배합에 영향을 주는 범위다. 이후 3D에서 높이대별로 다른 섹션의 건물이 겹칠 수 있다. 위로 성장하는 건물은 해당 접점에서 소유 섹션을 상속하고, 섹션 경계를 넘는 돌출이나 연결교는 양쪽의 실제 공간 여유로 승인한다.

## 2. 섹션을 건물 덩어리로 올린다

섹션에는 하나의 고정 테마 대신 **건물 용도의 가중치 묶음**을 배정한다. 상위 호화도는 섹션 중앙값과 범위로 기록하고, 개별 건물은 접점 주변의 표본을 추가로 읽는다. 같은 섹션에서도 번화한 접속부와 뒤편의 좁은 증축부를 만들 수 있다.

| 현장 신호 | 자주 배치할 건물 | 입체 연결 |
| --- | --- | --- |
| 높은 호화도, 강한 흐름, 여러 연결점 | 아케이드, 큰 업무·상업 건물, 드문 플라자 외관 | 큰 개방층이나 회랑이 통행을 나누고 합친다. |
| 중간 호화도, 길게 이어진 흐름 | 점포 겸 주택, 여러 규모의 상가 증축 | 좁은 통로를 따라 점포 앞면이 연속되고 다른 높이의 상가층으로 갈라진다. |
| 주변보다 낮은 호화도, 지지체가 많고 작은 틈이 반복됨 | 공동주택, 소규모 혼합용도 건물 | 공동 계단, 건물 사이 참, 공유 테라스가 여러 높이에서 이어진다. |
| 여유 부피가 크거나 층간통로의 작업측에 가까움 | 설비동, 물류동 | 높은 작업 공간, 하역 데크, 점검 계단이 서로 다른 높이의 통행점에 접속한다. |

생성의 기준 단위는 `{volume, supports, walkSurfaces, ports, voids}`를 반환하는 건물 템플릿이다. 크기 후보는 격자 한 칸부터 코어 층의 여러 높이대를 차지하는 건물까지 둔다. 크기와 층수는 코어 층고, 지지 여유, 건물 용도, 허용 공간에서 결정한다. 규모가 작은 건물을 많이 놓을 수 있고, 한 큰 건물의 상부에 다른 용도와 크기의 건물이 얹힐 수 있다.

1. **지지체와 연결점에서 시작한다.** 상위 통로의 출입구와 가깝고 구조적으로 지지되는 후보를 고른다. 높이는 지지면과 출입구 접속에 맞춘다. 여러 개의 코어 구조 지지점이 허용될 수 있다.
2. **먼저 주요 건물 몇 개를 놓고 바깥으로 자란다.** 이미 배치한 건물의 옆면, 계단참, 구조적으로 유효한 옥상·보·기둥을 다음 배치 후보로 등록한다. 새 건물의 입구는 사용 가능한 기존 포트와 맞거나, 짧은 계단·데크를 확보해야 한다. 긴 변이나 출입면 방향은 주변 노이즈의 흐름을 따라 점수를 얻는다. 직교와 45°부터 사용하고, 회전 결과의 실제 부피를 검사한다.
3. **크기가 다른 덩어리가 겹쳐 보이게 배치한다.** 같은 `x,z`를 공유해도 높이 구간이 다르면 배치할 수 있다. 외벽 틈, 높은 빈 공간, 출입구 전면의 여유, 아래가 비는 연결교 공간을 별도 예약한다. 부피 충돌, 공중정원 침범, 사용할 출입구 소실, 유효한 지지점 부재가 있으면 다음 후보를 검사한다.
4. **구조 지지를 기록한다.** 건물의 하중은 코어 구조물 또는 이미 지지된 건물로 이어져야 한다. 간소화한 모델로 지지 가능한 면적, 돌출 한계, 누적 하중을 검사한다. 연결교가 양끝에 접속하더라도, 별도 지지 승인 없이 건물을 떠받치는 것으로 계산하지 않는다.
5. **증축과 붕괴를 적용한다.** 추가 점포, 데크, 철제 연결교 등은 원래 건물의 출입구와 구조 지지에 붙는다. 붕괴·매몰은 점유 공간과 지지 관계를 바꾸는 연산으로 처리한다. 떨어져 전복된 구조물은 원래 외장과 창 위치를 보존하며, 현재의 지지·접근 상태는 별도로 계산한다.

섹션이 어떤 테마로 보일지는 건물 수보다 **같이 이어지는 면**에서 결정된다. 아케이드가 모인 곳은 여러 층의 난간과 상가가 하나의 빈 공간을 감싼다. 주거 건물이 모인 곳은 작은 발코니와 계단참이 계단식으로 드러난다. 주 구조, 나중에 붙인 통로, 붕괴 흔적에는 다른 마감 계열을 쓸 수 있다. 가까이에서 읽히는 셔터·창틀·배관·점포 표기는 일상 규모를 지키고, 단지의 겹침과 깊은 빈 공간이 낯선 전체 윤곽을 만든다.

## 3. 동선은 높이를 가진 포트 그래프로 만든다

노드는 `입구 / 복도 교차점 / 계단참 / 공용 데크 / 교량 접점 / 상위 연결점`이다. 간선은 캐릭터가 통과할 수 있는 실제 표면과 여유 공간을 참조한다. 섹션을 만드는 필드 경로가 보행 경로를 대신하지 않는다.

- **건물 내부:** 각 입구에서 공용 복도와 계단참에 닿는 경로를 템플릿이 반환한다. 계단과 경사로는 고도 차, 머리 공간, 참의 깊이, 출입 방향을 검사한다. 층과 건물마다 서로 다른 고도를 사용할 수 있다.
- **섹션 내부:** 새 건물의 주 입구를 이미 열린 포트에 연결하면서 접근 가능한 집합을 키운다. 연결이 필요하면 포트 사이에서 짧은 복도, 외부 참, 계단, 경사로를 조합한다. 생성 결과는 벽 안쪽에서 시작하는 길도, 아래가 비는 길도 포함할 수 있다.
- **섹션 사이:** 같은 높이와 방향이 맞는 포트, 또는 계단·경사로로 잇기 쉬운 포트들을 거리순으로 찾는다. 길이, 높이 차, 지지 비용, 비워둔 시야 침범을 검사한다. 유효 후보 중 첫 연결로 서로 닿게 만들고, 이후에는 기존 경로보다 충분히 짧거나 두 번째 높이 경로를 만드는 후보를 추가한다. 연결교 높이는 포트 좌표에서 결정한다.
- **코어 접속:** 상위 연결점과 맞닿는 공용 포트는 보호한다. 시작 지점에서 중앙 통로에 도달하고, 해당 대단지에 배정된 가장자리 통로가 있다면 거기에도 도달할 수 있어야 한다. 필수 경로는 출입구, 연결교, 계단참을 따라 이어지므로 코어 슬래브를 보행로로 가정할 필요가 없다.

간선의 비용은 이동 시간과 높이 변화로 계산한다. 붕괴 후 통행이 불가능해진 간선을 제거하고 도달성을 다시 검증한다. 필수 포트가 단절되면 해당 붕괴를 거부하거나 같은 높이대에 유효한 우회를 먼저 배치한다. 모든 섹션이 외부 골목을 공용으로 참조할 필요는 없다. 한 섹션에서 위층 상가를 지나 옆 섹션으로 건너간 뒤, 거기의 계단으로 내려오는 동선을 주요 검증 사례로 사용한다.

## 4. 생성된 공간에서 연출 지점을 뽑는다

연출 지점은 창, 난간, 데크처럼 플레이어가 실제로 접근할 수 있는 위치에서 선정한다. 창을 통해 첫 거대 구조물을 부분적으로 볼 수 있는 후보를 시작 구역에서 고른다. 가까운 창틀과 맞은편 생활 시설, 그 뒤의 먼 건축 덩어리가 한 방향에서 깊이 차로 읽혀야 한다. 이어지는 경로에서는 아래위의 상가, 다른 높이의 횡단, 규칙적인 중앙 구조물이 차례로 보일 수 있도록 후보를 비교한다.

플레이어 눈높이에서 시선 샘플을 쏴 창·개방부가 실제로 열려 있는지 검사한다. 시작 구역에서는 코어 전체 윤곽이 한꺼번에 드러나는 후보를 피하고, 중앙으로 접근할 때는 전면 건물 사이의 빈 공간 너머로 통로 일부가 드러나는 지점을 남긴다. 상위 계획의 원형으로 모인 빛과 공중정원 시야는 예약 공간으로 보호한다. 높은 곳의 장면도 그곳까지 도달 가능한 그래프 경로가 있어야 유효하다.

## 구현 경계와 완료 기준

```text
P03 상위 마스크 + 노이즈 + 호화도 + 포트
  → 도시 섹션 지도
  → 건물 부피 + 지지 그래프 + 포트 그래프
  → 증축과 붕괴
  → 검증된 도시 계획
  → P05 3D 미리보기 및 게임 연결
```

P04의 결과는 `sections, buildings, supports, ports, links, voids, viewpoints`를 담은 도시 계획이다. 섹션 ID는 층과 중심 후보 좌표, 건물 ID는 섹션과 지지 접점에서 결정한다. 정렬과 난수 분기는 고정 ID를 기준으로 삼는다. 코어 층 단위로 계획을 계산하고, 청크는 경계 상자 인덱스로 해당 구간에 겹치는 부피만 조회한다. 청크를 먼저 읽은 순서에 따라 섹션과 다리가 달라지면 안 된다.

첫 검증 범위는 **한 대단지 내부의 서로 다른 높이대와, 옆 대단지로 이어지는 연결교 하나**다. 기존 `width=512`, `seed=9999` 프리셋을 사용하고, 코어 층고는 별도 입력으로 받는다. 단면과 높이별 오버레이에서 다음을 확인한다.

- 같은 호화도에서 노이즈를 바꾸면 섹션의 연장 방향과 경계가 달라지고, 같은 노이즈에서 호화도를 바꾸면 중심의 우선도·섹션 범위·건물 규모와 용도 배합이 달라진다.
- 크기가 다른 건물이 수직으로 포개지고 서로 다른 높이의 입구에 접속한다. 필수 경로에는 코어 슬래브를 걷는 간선이 없어도 된다.
- 상위 예약 공간을 침범하지 않고 모든 건물의 지지 경로가 유효하다. 연결교를 따라 넘어가 다른 건물에서 내려올 수 있다.
- 시드를 고정하면 섹션 경계, 배치, 연결이 동일하다. 주요 붕괴 후에도 필수 포트에 도달할 수 있다.

가중치와 표본 간격은 첫 미리보기용 값이다. 게임의 현재 64블록 청크 높이에는 이 도시 계획의 높이를 끼워 맞추지 않는다. P05에서 코어 층고와 수직 청크를 실제 연결할 때 같은 좌표 계약을 사용한다.
