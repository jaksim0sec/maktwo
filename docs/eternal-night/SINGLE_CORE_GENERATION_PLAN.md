# 영원한 밤 · 단일 코어 생성 계획

> 상태 — 계획 초안  
> 참조 — [세계관 원안](WORLD_CONCEPT.md) · [현재 엔진 구조](../ARCHITECTURE.md)

첫 마일스톤은 코어 한 층의 2D 평면을 생성하고, 구조물 배치·보행 동선·타일별 호화도를 한 지도에서 검증하는 것이다. 같은 좌표로 대단지의 건물 배치와 인접 두 층의 3D 골격을 생성한다. 여러 코어의 연결, 열차 운행, 건물 내부와 폐허 디테일은 후속 단계다.

## 모식도의 요소

첨부 모식도는 위치 관계를 보여준다. 실제 폭·반지름·거리의 비율은 규모 검토에서 정한다.

| 모식도 | 요소 | 배치 |
| --- | --- | --- |
| 흰색 외곽 | 코어 층의 바닥 경계 | 정팔각형 |
| 빨간 원 | 메인 층간통로 | 코어 중심의 원통 1개 |
| 안쪽 파란 점 | 공중정원 | 중앙 원통 주변의 원형 개구부 4개 |
| 바깥 파란 점 | 미니 층간통로 | 네 방향 가장자리 쪽에 1개씩 |
| 보라색 | 주 동선과 미래 열차 부지 | 중앙부에서 바깥쪽으로 뻗는 4축 |
| 초록색 | 대단지 배치 구역 | 주 동선 사이의 4구역 |

## 코어 한 층 권장 2D 비율 프리셋 (2026-11-13)

> 상태: 사용자가 2D 미리보기에서 선택한 **권장값**. 알고리즘의 기본값이나 세계관상의 최종 확정값을 뜻하지 않는다. 층고는 이 프리셋에서 제외한다.
>
> 출처: [core-floor-preview.html](core-floor-preview.html)의 시드 9999 설정 화면. 참조 구현: `src/worldgen/eternal-night-core-floor.js`.

**기준 가로폭** `width = 512`, **시드** `seed = 9999`.

| 항목 | 함수 파라미터 | 권장값 |
| --- | --- | ---: |
| 중앙부 반경 | `centerRadius` | `0.18` |
| 중앙 원통 반경 | `mainShaftRadius` | `0.062` |
| 공중정원 중심 위치 | `gardenOffset` | `0.115` |
| 공중정원 반경 | `gardenRadius` | `0.015` |
| 미니 층간통로 중심 위치 | `miniShaftOffset` | `0.81` |
| 미니 층간통로 반경 | `miniShaftRadius` | `0.037` |
| 주 동선 반폭 | `roadHalfWidth` | `0.01` |
| 외곽 여백 폭 | `rimWidth` | `0.015` |
| 호화도 감소폭 | `luxuryFalloff` | `0.2` |
| 그물형 노이즈 간격 | `noiseCellSize` | `0.03` |

**해석:** 위 비율 10개는 모두 코어 가로폭의 절반인 `a = width / 2`를 기준으로 한다. 실제 길이는 `값 × a`. `width = 512`일 때 `a = 256`이며, 예컨대 중앙부 반경은 `46.08`, 중앙 원통 반경은 `15.872` 좌표 단위다. 원 4개와 미니 통로 4개는 각각 중심으로부터 축 방향으로 `gardenOffset × a`, `miniShaftOffset × a`만큼 떨어져 있다. 주 동선의 **전체 폭**은 `2 × roadHalfWidth × a`이다.

시드는 비율이 아닌 재현용 정수다. 가로폭 512는 이번 시연에서 선택한 **크기 기준값**이며 다른 크기에 적용하려면 위 10개 비율을 유지해 스케일링한다. 호화도 계산의 세부 규칙과 실제 크기 적절성은 추가 검증 대상이다.

**검증 범위:** 화면 표시값을 전사하고 함수 인자명 및 `a` 기준을 코드에서 대조했다. 실제 게임 내부 적용·성능/동선 검증은 수행하지 않았다.

### P01 · 규모와 평면

코어 중심을 (0, 0)으로 두고, 중심에서 수평·수직 변까지의 거리를 a로 둔다. 층 바닥은 다음 두 조건을 모두 만족하는 점이다.

- max(|x|, |z|) ≤ a
- |x| + |z| ≤ √2 × a

평행한 두 변 사이의 폭은 2a다. 가로폭은 중앙부와 양쪽 통로에 필요한 폭, 대단지 4개의 가용 면적, 도보 횡단 시간을 함께 보고 결정한다. 횡단 시간은 실제 주 동선 길이와 게임의 이동 속도를 기준으로 계산한다. 층고는 기존에 정의한 높이 규격을 참조한다. 정확한 수치와 출처는 이 초안에서 확인하지 못했다.

### P02 · 중앙부와 공중정원

중앙부의 범위, 메인 원통의 반지름, 공중정원의 반지름과 중심에서의 거리, 미니 층간통로의 위치를 각각 매개변수로 둔다. 메인 층간통로는 원통형 외곽으로 먼저 표현한다. 안쪽 원 4개는 층 바닥에서 빠지는 영역이며, 각 구멍 주위의 보행 공간을 확보한다. 바깥쪽 원 4개는 미니 층간통로 자리다.

현재 세계관 문서에는 중앙부 공중정원을 원형 개구부 하나로 기술한다. 이 계획은 최신 모식도에 따라 **중앙 원통 주변에 개구부 네 개**를 배치한다. 이후 하늘 셰이더에서 별처럼 보이는 빛을 표현할 때는 개구부의 월드 좌표를 참조할 수 있도록 한다.

### P03 · 동선과 타일별 호화도

보라색 4축을 주 동선이자 향후 열차 부지로 예약하고, 중앙부와 가장자리 미니 층간통로를 연결한다. 중앙부에서는 공중정원을 피해서 메인 원통까지 갈 수 있어야 한다. 보라색 구역에 속한 타일의 호화도는 항상 최고값인 1이다.

대단지 호화도는 **각 대단지의 가장자리에서 내부로 갈수록 감소**하는 것으로 우선 해석한다. 보라색 주 동선과 맞닿은 출입구를 시작점으로 삼고, 보행 가능한 최단 이동 거리에 따라 값을 낮추는 방식이 초안이다. 이 해석은 아직 확정 전이다. P03에서는 계획된 출입구와 이동 가능 영역을 기준으로 히트맵을 만들고, P04에서 실제 입체 동선이 정해지면 보행 접근성을 별도 값으로 계산한다.

### P04 · 대단지 생성

[대단지 생성 알고리즘 설계](DISTRICT_GENERATION_DESIGN.md)에 따라 상위 노이즈와 호화도를 도시 섹션으로 변환한다. 건물은 코어 구조나 다른 건물에서 여러 높이로 자란다. 통행은 건물 바닥·계단참·데크·연결교의 3D 포트로 연결한다.

### P05 · 3D 골격과 게임 연결

평면에서 결정한 같은 좌표로 팔각 바닥, 중앙 원통, 공중정원 개구부, 미니 층간통로를 생성해 인접 두 층을 검증한다. 현재 MakTwo의 청크 높이는 64블록이다. 실제 월드에 넣는 시점에는 수직 청크와 로딩 범위를 별도 마일스톤으로 다룬다. 단일 코어 전체를 한꺼번에 복셀로 만들 필요는 없다.
