# 영원한 밤 · 단일 코어 생성 계획

> 상태 — 계획 초안  
> 참조 — [세계관 원안](WORLD_CONCEPT.md) · [현재 엔진 구조](../ARCHITECTURE.md)

첫 마일스톤은 코어 한 층의 2D 평면을 생성하고, 구조물 배치·보행 동선·타일별 호화도를 한 지도에서 검증하는 것이다. 같은 좌표로 대단지의 건물 배치와 인접 두 층의 3D 골격을 생성한다. 여러 코어의 연결, 열차 운행, 건물 내부와 폐허 디테일은 후속 단계다.

## 모식도의 요소

첨부 모식도는 위치 관계를 보여준다. 실제 폭·반지름·거리의 비율은 규모 검토에서 정한다.

| 모식도 | 요소 | 배치 |
| --- | --- | --- |
| 흰색 외곽 | 코어 층의 바닥 경계 | 정팔각형 |
| 빨간 원 | 메인 층간통로 | 코어 중심의 원통 1개 |
| 안쪽 파란 점 | 공중정원 | 중앙 원통 주변의 원형 개구부 4개 |
| 바깥 파란 점 | 미니 층간통로 | 네 방향 가장자리 쪽에 1개씩 |
| 보라색 | 주 동선과 미래 열차 부지 | 중앙부에서 바깥쪽으로 뻗는 4축 |
| 초록색 | 대단지 배치 구역 | 주 동선 사이의 4구역 |

### P01 · 규모와 평면

코어 중심을 (0, 0)으로 두고, 중심에서 수평·수직 변까지의 거리를 a로 둔다. 층 바닥은 다음 두 조건을 모두 만족하는 점이다.

- max(|x|, |z|) ≤ a
- |x| + |z| ≤ √2 × a

평행한 두 변 사이의 폭은 2a다. 가로폭은 중앙부와 양쪽 통로에 필요한 폭, 대단지 4개의 가용 면적, 도보 횡단 시간을 함께 보고 결정한다. 횡단 시간은 실제 주 동선 길이와 게임의 이동 속도를 기준으로 계산한다. 층고는 기존에 정의한 높이 규격을 참조한다. 정확한 수치와 출처는 이 초안에서 확인하지 못했다.

### P02 · 중앙부와 공중정원

중앙부의 범위, 메인 원통의 반지름, 공중정원의 반지름과 중심에서의 거리, 미니 층간통로의 위치를 각각 매개변수로 둔다. 메인 층간통로는 원통형 외곽으로 먼저 표현한다. 안쪽 원 4개는 층 바닥에서 빠지는 영역이며, 각 구멍 주위의 보행 공간을 확보한다. 바깥쪽 원 4개는 미니 층간통로 자리다.

현재 세계관 문서에는 중앙부 공중정원을 원형 개구부 하나로 기술한다. 이 계획은 최신 모식도에 따라 **중앙 원통 주변에 개구부 네 개**를 배치한다. 이후 하늘 셰이더에서 별처럼 보이는 빛을 표현할 때는 개구부의 월드 좌표를 참조할 수 있도록 한다.

### P03 · 동선과 타일별 호화도

보라색 4축을 주 동선이자 향후 열차 부지로 예약하고, 중앙부와 가장자리 미니 층간통로를 연결한다. 중앙부에서는 공중정원을 피해서 메인 원통까지 갈 수 있어야 한다. 보라색 구역에 속한 타일의 호화도는 항상 최고값인 1이다.

대단지 호화도는 **각 대단지의 가장자리에서 내부로 갈수록 감소**하는 것으로 우선 해석한다. 보라색 주 동선과 맞닿은 출입구를 시작점으로 삼고, 보행 가능한 최단 이동 거리에 따라 값을 낮추는 방식이 초안이다. 이 해석은 아직 확정 전이다. P03에서는 계획된 출입구와 이동 가능 영역을 기준으로 히트맵을 만들고, P04에서 골목이 정해지면 실제 경로를 기준으로 다시 계산한다.

### P04 · 대단지 생성 순서

1. 팔각형 바닥에서 중앙부·주 동선·층간통로·공중정원 부지를 확보하고, 그 사이에 대단지 구역 네 곳을 잡는다.
2. 주 동선에 접한 출입구에서 골목을 뻗고, 골목에 접근할 수 있도록 필지를 나눈다.
3. 각 필지에 호화도에 따른 건물 용도와 높이 범위를 배정한다. 저층과 고층 건물의 배치, 골목 접근성, 통로 침범 여부를 건물 덩어리로 먼저 확인한다.

### P05 · 3D 골격과 게임 연결

평면에서 결정한 같은 좌표로 팔각 바닥, 중앙 원통, 공중정원 개구부, 미니 층간통로를 생성해 인접 두 층을 검증한다. 현재 MakTwo의 청크 높이는 64블록이다. 실제 월드에 넣는 시점에는 수직 청크와 로딩 범위를 별도 마일스톤으로 다룬다. 단일 코어 전체를 한꺼번에 복셀로 만들 필요는 없다.
