# 영원한밤 · 텍스처 및 건축 부품 전시장

선택 가능 월드는 **2개**다.

| 월드 | 내용 |
| --- | --- |
| TextureGallery | 평면 위 기존 큐브/유리 재질 및 신규 30개 건축 마감 텍스처 블록을 각각 하나씩 전시 |
| PartsGallery | 평면 위 13개 건축 부품군 × 5종, 총 **65개의 고유 부품**을 각각 독립 전시 |

**건물 자동 생성이나 서로 다른 부품을 합쳐 한 채를 조립하는 월드는 제거했다.** 부품들은 각각 고유 블록 ID(116~180)로 크리에이티브에서 선택하고 설치할 수 있다. 설정의 **건축 부품 분류**를 선택하면 해당 5개 샘플 앞으로 이동한다. 크리에이티브 인벤토리에서도 기존 **건축재**와 신규 **부품**이 별도 탭으로 나뉜다.

부품 전시는 종류별 별도 열, 샘플 가로 간격 7블록, 유형별 세로 간격 9블록으로 구성한다. 원래 재질 블록 ID(0~115)와 70개 32×32 텍스처 레이어는 유지하고, 부품 모델을 구성하는 각 면에 기존 재질을 독립 지정한다. 창틀과 유리문 등은 **불투명 프레임 / 반투명 유리** 렌더링을 분리한다.

과거 `BuildingShopHouse` 등의 월드 이름에 저장된 로컬 데이터는 삭제하지 않는다. 다만 월드 선택 UI에는 표시하지 않는다. 기존 `ruins` 호환 생성기는 플레이어에게 제공되지 않는다.

**구현 범위:** 단독으로 선택·설치할 수 있는 블록 크기의 건축 모듈. 베란다·환풍기·간판을 포함한 65개 어셋의 형상과 재질 배치를 구현했다. 여러 블록에 걸친 자동 증축, 자유형 교량, 간판 문구 편집, 모터 애니메이션은 아직 없다.

기본 건축 부품의 45° 방향 회전, 계단 일체 난간 자동 접합, 얇은 일체형 창호, 상세 팬 로터는 [부품 명세](ARCHITECTURAL_COMPONENTS.md)를 참조한다.
