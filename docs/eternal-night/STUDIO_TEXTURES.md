# 건축 소재 검증 월드

월드 선택에는 텍스처 전시장 1개와 독립된 건물 5개만 표시한다. 기존 로컬 월드 저장 데이터는 삭제하지 않는다. 이전 월드의 생성 함수를 보존하여 과거 데이터와 테스트 호환성을 유지한다.

| 선택 월드 | 내용 |
| --- | --- |
| TextureGallery | 평면 위 기존 큐브·유리 및 신규 재질 블록 각 1개씩 |
| BuildingShopHouse | 단일 상가주택 |
| BuildingOffice | 단일 근린 업무시설 |
| BuildingWalkup | 단일 다세대주택 |
| BuildingArcade | 단일 아케이드 |
| BuildingService | 단일 설비·복합건물 |

## 추가한 30종 소재

기존 0~85 블록 ID와 40개 텍스처 레이어는 고정. 신규 블록 86~115와 텍스처 레이어 41~70을 부가한다. 각 재질은 32×32 실제 픽셀 텍스처로 생성되어 게임 렌더러와 아이템 아이콘에 연결된다.

| 계열 | 다섯 소재 |
| --- | --- |
| tile | 세로 백색 자기질 타일 · 회색 정방 타일 · 대형 포세린 타일 · 소형 모자이크 타일 · 균열 유약 타일 |
| stone | 회색 화강석 · 분홍 화강석 · 검정 화강석 · 테라조 인조석 · 대리석 무늬석 |
| concrete | 거푸집 노출 콘크리트 · 점박이 도장벽 · 거친 모르타르 · 매끈한 미장벽 · 보수 흔적 콘크리트 |
| brick | 적벽돌 · 회색 벽돌 · 콘크리트 조적 블록 · 백색 치장벽돌 · 미장한 조적벽 |
| metal | 검정 도장철 · 아연도금 강판 · 부식 철판 · 브러시 스테인리스 · 절곡 골강판 |
| floor | 회색 보도블록 · 상업용 비닐타일 · 노후 장판 · 거친 아스팔트 · 목재 마루 |

소재별 줄눈·광물 입자·거푸집 이음·조적 줄눈·금속 결·바닥재 패턴을 다르게 생성한다. 색상은 블록 색 팔레트에서 조합한다. 건물 외벽은 신규 소재를 사용하고 건물 내부·계단은 기존 v5 절차적 건축을 재사용한다. 전체 코어 3D, 13종 건축 부품 라이브러리, 노후화 레이어는 이 단계에 포함하지 않는다.
