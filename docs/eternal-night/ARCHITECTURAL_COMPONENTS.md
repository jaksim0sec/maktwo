# 독립 건축 부품 시스템 · v1.15

**이전의 건물 전체를 생성하는 시연 로직은 폐기**했다. 부품은 건물의 소속이나 층별 조합 규칙 없이 독립적인 블록으로 제작된다.

| --- | --- |

- `src/core/part-library.js`: 13계열·65종의 고정 ID, 형상, 개별 재질 부품을 관리
- `src/worldgen/part-gallery.js`: 서로 닿지 않는 개별 부품 샘플만 배치
- `src/core/blocks.js`: 각 샘플을 크리에이티브에서 선택 가능한 블록으로 등록
- `src/core/shapes.js`: 렌더·충돌·선택에 공통으로 사용하는 부분 형상
- `src/client/mesher.js`: 재질별 면 생성 및 창/유리문의 투명 패스 분리

### 한계

현재는 **0.8m 크기의 한 블록 안에 들어가는 건축 부품 모델**이다. 여러 블록을 점유하는 실제 규모의 문틀·계단실이나 베란다 전체를 자동으로 이어 짓는 멀티블록 빌더는 아니다. 환풍기는 정적이고 간판은 조형 글자만 있으며 편집 가능한 간판 문구는 구현하지 않았다. 이전 월드 저장 데이터를 삭제하지 않는다.
