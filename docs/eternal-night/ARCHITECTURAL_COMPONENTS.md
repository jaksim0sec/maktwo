# 부품 기반 건축 1차 구현

고정 건물 원형의 스튜디오 생성 경로를 부품 합성기로 교체. 기존 `architecture-v3.js`는 이전 `ruins` 월드/저장 호환을 위해 유지.

부품군: 통로·현관·계단입구·벽·기둥·창틀·가벽·문·계단·조합형 간판·인테리어. 각 5개 기본 변형. 층별 평면은 독립 조합한 날개, 후퇴, 불규칙 공백을 갖고, 계단실과 복도 축은 보존한다. 시드/위치별로 재질·문·창호·간판 등을 달리 조합한다.

렌더/충돌 보조값은 블록 ID와 별도인 청크 `styles`에 보관한다. 1차 구현에서 일부 파츠는 기존 블록 형상/재질을 재사용한다.

미완료: 실제 다층 코어 구현, 자유 형상 공중 교량, 부품별 상호작용 확대, 5개 타입별 독립 3D 파츠 모델, 현실 크기 정확도와 모바일 실기 테스트.
